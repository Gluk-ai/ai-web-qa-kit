# Security policy

## Authorized use only
These tools probe websites, databases and chatbots. Run them only against systems you own or have **written permission** to test. Unauthorized testing may be illegal where you live.

Default runs are read-only. `check_rls.py --write-probe` creates data and is off by default.

## Reporting a vulnerability in this kit
Email **hello@corepulsedev.com** with the subject `ai-web-qa-kit security`. Please do not open a public issue for vulnerabilities.
